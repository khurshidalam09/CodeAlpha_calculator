# 🧮 Professional Calculator

A clean, responsive, and interactive **Calculator Web Application** built using **HTML, CSS, and JavaScript**. The project provides a modern calculator interface with arithmetic operations, keyboard/NumPad support, error handling, and interactive button effects.

## 📌 Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* `%` Percentage operation
* 🔢 Decimal number support
* 🧹 Clear (`C`) functionality
* ⌫ Delete (`DEL`) functionality
* ⌨️ Full keyboard support
* 🔢 NumPad support
* ↵ Enter key for calculation
* ⎋ Escape key to clear the display
* ⚠️ Basic calculation error handling
* ✨ Interactive button hover and click animations
* 📱 Responsive layout
* 🎨 Modern dark-themed user interface

## ⌨️ Keyboard Controls

The calculator supports both the standard keyboard and numeric keypad.

| Key         | Function              |
| ----------- | --------------------- |
| `0 - 9`     | Enter numbers         |
| `+`         | Addition              |
| `-`         | Subtraction           |
| `*`         | Multiplication        |
| `/`         | Division              |
| `.`         | Decimal               |
| `%`         | Percentage            |
| `Enter`     | Calculate result      |
| `Backspace` | Delete last character |
| `Escape`    | Clear calculator      |

### NumPad Support

If your keyboard has a numeric keypad, the following are also supported:

```text
NumPad 0 - 9
NumPad +
NumPad -
NumPad *
NumPad /
NumPad .
NumPad Enter
```

> **Note:** Num Lock should generally be enabled for NumPad number input.
