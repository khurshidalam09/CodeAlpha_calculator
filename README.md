## ⌨️ Keyboard Controls

The calculator supports both the standard keyboard and numeric keypad.

| Key         | Function              |
| ----------- | --------------------- |
| `0 - 9`     | Enter numbers         |
| `+`         | Addition              |
| `-`         | Subtraction           |
| `*`         | Multiplication        |
| `/`         | Division              |
| `.`         | Decimal               |
| `%`         | Percentage            |
| `Enter`     | Calculate result      |
| `Backspace` | Delete last character |
| `Escape`    | Clear calculator      |

### NumPad Support

If your keyboard has a numeric keypad, the following are also supported:

```text
NumPad 0 - 9
NumPad +
NumPad -
NumPad *
NumPad /
NumPad .
NumPad Enter
```

> **Note:** Num Lock should generally be enabled for NumPad number input.

## ⚙️ How It Works

The calculator accepts user input through either the on-screen buttons or the physical keyboard.

For example:

```text
10 + 20
```

After pressing `=` or `Enter`:

```text
30
```

Another example:

```text
100 / 4
```

Result:

```text
25
```

## 🔒 Security Note

This project is designed as a **basic educational calculator**.

The current implementation uses JavaScript expression evaluation for arithmetic calculations. For a production-grade application, the calculation engine should use a dedicated expression parser instead of dynamically evaluating expressions.
